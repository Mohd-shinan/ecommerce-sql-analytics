# E-Commerce Sales & Customer Analytics

## Project Overview

This project focuses on analysing e-commerce sales data using **MySQL**. The objective is to explore sales performance, customer spending behaviour, product category performance, payment methods, and regional sales trends through SQL queries.

The project demonstrates practical SQL skills by answering business-related questions using real-world sales data.

## Tools & Technologies

- MySQL Workbench
- CSV Dataset

## Dataset Description

The project uses an e-commerce sales dataset containing 5,000 sales records.

The dataset includes the following columns:

- `order_id`
- `order_date`
- `customer_id`
- `product_category`
- `region`
- `quantity`
- `unit_price`
- `discount`
- `payment_method`
- `delivery_days`
- `customer_rating`
- `revenue`

Dataset source:"https://www.kaggle.com/datasets/abbas829/e-commerce-sales-analytics-dataset"

## Database Structure

Database name: `sales_analysis`

Main table:
- `ecommerce_sales` – contains the sales transaction records.

Additional lookup tables:
- `customers` – contains distinct customer IDs.
- `categories` – contains distinct product categories.

## Business Questions Answered

1. What is the total revenue generated by the business?
2. What is the average revenue per order?
3. Which product category generates the highest revenue?
4. Which payment methods generate the most revenue?
5. Who are the top five highest-spending customers?
6. Which customers have placed more than five orders?
7. Which product categories sell the highest quantity?
8. Which regions generate the highest revenue?
9. How does delivery performance vary by product category?
10. Which customers spend more than the average customer spending?
11. How can customers be ranked based on total spending?
12. What is the sales summary for each product category?
